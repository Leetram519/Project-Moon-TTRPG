    const MELEE_FORMS

    Weapon dropdowns should always have a valid value.

    If a form or hand property is blank, or doesn't belong to the current weapon type, the UI can look correct while the stored value is still wrong. That can also prevent the expected bonus from being applied.

    These helpers keep weapon type, form, and hand values in sync so prepareData, clash rolls, and melee/ranged switching all behave the same way.

    Function: normalizeWeaponType(weaponType)

    Normalizes a weapon type.

    Melee is the default, so only an explicit "ranged" value is treated as ranged. Blank, null, or unknown values fall back to melee.

    Parameters

    Name Type Description
    weaponType string|null|undefined —

    Returns "melee"|"ranged" — —

    Function: defaultFormProperty(weaponType)

    Returns the default form property for a weapon type.

    Melee weapons default to Small, while ranged weapons default to Low Caliber.

    Parameters

    Name Type Description
    weaponType string|null|undefined —

    Returns string — —

    Function: normalizeWeaponFormProperty(weaponType, formProperty)

    Makes sure the form property is valid for the current weapon type.

    If it isn't, the weapon falls back to the default form for that type. This also prevents stale values when switching between melee and ranged, such as keeping Small stored after changing a weapon to ranged.

    Parameters

    Name Type Description
    weaponType string|null|undefined —
    formProperty string|null|undefined —

    Returns string — —

    Function: normalizeWeaponHandProperty(weaponType, handProperty)

    Makes sure the hand property is valid for the current weapon type.

    Ranged weapons currently only support Offensive 1H and Offensive 2H. If a weapon has an invalid or blank hand value, it falls back to Offensive 1H.

    Parameters

    Name Type Description
    weaponType string|null|undefined —
    handProperty string|null|undefined —

    Returns string — —

    Function: normalizeWeaponProperties(system = {})

    Normalizes all weapon properties in one pass.

    This keeps the weapon type, form, and hand values valid together. Used by prepareData, migrateData, clash rolls, and _preUpdate when switching a weapon between melee and ranged.

    @param — {{ weaponType?: string|null, formProperty?: string|null, handProperty?: string|null }|null|undefined} system

    Returns { weaponType: "melee"|"ranged", formProperty: string, handProperty: string — }
